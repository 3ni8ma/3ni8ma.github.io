# 3ni8ma.github.io

Personal site for Aarush Karak, built for Fraser Comp Sci Club Meeting 04.

Live at <https://3ni8ma.github.io/>.

No build step. The site is plain HTML, CSS, and JavaScript.

## Files

- `index.html` — home page
- `projects.html` — project list
- `terminal.html` — interactive terminal
- `styles.css` — shared styles and themes
- `script.js` — theme switcher and confetti
- `terminal.js` — terminal commands
- `me.jpg` — photo
- `resume.pdf` — public copy of the resume (phone number removed)
- `favicon.svg` — site icon

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
